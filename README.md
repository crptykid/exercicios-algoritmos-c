
# Exercícios de Algoritmos e Pensamento Computacional em C

## Descrição

Repositório desenvolvido para a prática de lógica de programação e
estruturas de repetição utilizando a linguagem C.

## Exercícios

1. **Consumo de água:** analisa o consumo mensal de cinco moradores
   e calcula a média geral.
2. **Cofrinho digital:** simula o acúmulo de moedas de R$ 0,50,
   R$ 1,00 e R$ 2,00.
3. **Média de atendimento:** calcula a média das notas de dez
   clientes e emite um alerta se a média for menor que 7.
4. **Meta de passos:** contabiliza as horas necessárias para atingir
   ou ultrapassar 10.000 passos.
5. **Média de curtidas:** calcula a média de curtidas de cinco
   publicações.

## Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Estruturas condicionais (`if` e `else`)
- Estruturas de repetição (`for`, `while` e `do while`)
- Contadores e acumuladores
- Operações aritméticas

## Linguagem utilizada

- C

## Objetivo

Praticar os fundamentos da programação por meio de problemas
do cotidiano, desenvolvendo o raciocínio lógico e a capacidade
de construir algoritmos.
